# BahisSandbox

TEKNOFEST 2026 - Bağımlılıklarla Mücadele Yarışması

## Nedir?
Instagram benzeri sahte sosyal medya uygulaması. 
BahisKalkanı ile birlikte çalışarak yasadışı bahis içeriklerini tespit edip kapatır.

## Özellikler
- 40 gönderi (normal + bahis karışımı)
- Tamamen offline çalışır, internet izni yok
- Semantics eklendi, BahisKalkanı metinleri okuyabiliyor
- Splash screen ve özel logo mevcut
